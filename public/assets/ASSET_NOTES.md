# 생성 이미지 기록

두 파일 모두 기본 내장 이미지 생성 도구로 만들었으며 `Sample.png`는 스타일·분위기 참고 이미지로만 사용했습니다.

## dark-hanji-bg.png

- 용도: 반응형 9:16 게임 배경 질감
- 프롬프트 요약: 짙은 자두·에스프레소 계열의 한국 한지 섬유, 중앙의 매우 은은한 온기와 가장자리 비네트, 오브젝트·문자·무대·달·별 없이 크롭 가능한 평면 질감.

## warm-hanji-screen.png

- 용도: 그림자가 투영되는 무대 막 질감
- 프롬프트 요약: 따뜻한 아이보리·밀색 한지, 중앙 백라이트와 절제된 가장자리 음영, 프레임·커튼·실루엣·오브젝트·문자 없이 마스크에 사용할 수 있는 균일한 평면 질감.

랜턴, 레일, 종이 오브젝트, 커튼, 그림자와 새 실루엣은 확대 선명도와 스테이지 확장성을 위해 Canvas 벡터 레이어로 분리했습니다.
