# 빌린 그림자

두 랜턴을 곡선 레일 위에서 움직여 세 종이 오브젝트의 그림자를 새 실루엣으로 합치는 9:16 모바일 웹 퍼즐입니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`, 엔진 테스트는 `npm test`로 확인합니다.

## 조작

- 마우스/터치: 랜턴 드래그
- `1` / `2`: 파란색/주황색 랜턴 선택
- `←` / `→`: 선택한 랜턴 미세 조정
- `R`: 재시작
- `F`: 전체화면

## 확장 구조

- `src/game-engine.js`의 `STAGE_ONE`에 랜턴, 오브젝트 단면, 깊이, 성공 임계값이 콘텐츠 데이터로 분리되어 있습니다.
- 좌표계는 `x`(가로), `y`(바닥 위 높이), `z`(스크린에서의 거리)를 사용하는 2.5D 공간입니다. 랜턴은 점광원, 오브젝트는 서로 다른 `z` 위치의 불투명 평면입니다.
- 각 오브젝트 꼭짓점에서 `L + k(P-L)` 광선과 `z=0` 스크린 평면의 교점을 구해 원근 투영합니다. 오브젝트가 광원에 가까울수록 그림자가 실제로 커집니다.
- 모든 랜턴이 모든 오브젝트를 투영합니다. 일부 빛만 가려진 영역은 색이 있는 반그림자, 모든 빛이 가려진 영역은 짙은 완전 그림자(umbra)가 됩니다.
- 목표 마스크도 정답 랜턴 좌표에서 같은 투영 함수로 매번 산출합니다. 손으로 움직이는 가짜 그림자 조각이나 별도 목표 실루엣 좌표가 없습니다.
- `calculateShadowSimilarity()`는 임의 개수의 랜턴을 받으며, 현재 완전 그림자와 목표 완전 그림자의 Jaccard 지수(교집합 / 합집합)를 계산합니다.
- 렌더러와 히트 테스트도 설정의 랜턴 배열을 순회하므로 다음 스테이지에서 랜턴을 추가할 수 있습니다.
